# Açaí do Vale

## Localização e entrega

- ViaCEP: apenas preenchimento do endereço pelo CEP.
- Photon (OpenStreetMap): geocodificação gratuita do endereço completo.
- Leaflet + OpenStreetMap: mapa e marcador arrastável.
- OSRM: cálculo da rota real pelas ruas.
- Google Maps/Google Geocoding: não é necessário.
- Nominatim: não é utilizado pelo aplicativo.

Para localizar automaticamente uma residência, informe CEP completo, rua e número. O usuário também pode clicar no mapa ou arrastar o marcador para corrigir a posição.

O servidor público do Photon é destinado a uso razoável; aplicações de grande volume devem hospedar sua própria instância. Consulte a documentação oficial do Photon para limites e disponibilidade.
